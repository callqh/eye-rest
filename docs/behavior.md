# 产品行为规则

本页描述当前实现，默认使用 20 分钟、休息 20 秒、延后 5 分钟。实际时长以设置为准。

## 一轮休息的状态

```text
使用中 working
  ├─ 使用时间到 → 待休息 due
  └─ 点击「现在休息」 → 待休息 due

待休息 due
  ├─ 点击「开始休息」 → 休息中 resting
  ├─ 延后 → 按延后时长计时的 working
  └─ 跳过 → 完整新周期的 working

休息中 resting
  ├─ 按键、点击、滚动 → 重置休息时长
  ├─ 仅移动鼠标 → 继续休息，不重置
  └─ 达到休息时长 → 等待回来 awaitingReturn

等待回来 awaitingReturn
  ├─ 新的键盘 / 鼠标活动 → 完整新周期的 working
  ├─ 点击「开始下一轮」 → 完整新周期的 working
  └─ 仅时间流逝、收起弹框 → 仍然等待
```

- 提醒出现本身不代表开始或完成休息，必须先点击「开始休息」。
- 普通使用阶段不以无输入推断休息；阅读时也累计使用时间。
- 休息完成只计入一次；重复输入或重复点击开始不能重置已经开始的使用时间。
- 等待时识别按键、点击、滚动、鼠标移动和拖动；活动基线在休息完成和系统恢复时重置，旧活动不触发下一轮。
- 「再休息一会儿」只收起弹框，按钮自身不启动计时；后续新的活动仍可以自动开始。

## 窗口与图图

- 菜单栏图标和悬浮说明只展示状态，不展示倒计时数字。
- 点击菜单栏后的弹框展示倒计时、进度环和图图图片。
- 全屏遮罩覆盖全部显示器，提供开始休息、延后和跳过；不是系统锁屏。
- 全屏共用一层实时模糊材质，中央不另加黑色玻璃卡片；macOS 26 次级按钮采用 Clear Liquid Glass。
- 提醒阶段可让图图缓慢走动；主动休息时图图停止走动，保留正面坐姿，不淡出。
- 休息遮罩不展示秒数；打断时只用文字提醒重新休息。
- 完成后自动弹出等待面板，收起后不重复自动弹出；可再次点击菜单栏打开。

## 暂停、锁屏与睡眠

| 场景 | 结果 |
| --- | --- |
| 手动暂停 | 保留剩余使用或休息时间，新的活动不会解除暂停 |
| 手动恢复 | 继续剩余时间 |
| 使用阶段锁屏 / 睡眠不足休息时长 | 恢复时保留剩余使用时间 |
| 使用阶段锁屏 / 睡眠达到休息时长 | 恢复为完整新使用周期 |
| 主动休息时离开达到休息时长 | 完成当前休息，进入等待回来 |
| 已完成休息后锁屏 / 睡眠 | 恢复后仍等待新的活动，不以解锁事件直接开始 |

多种挂起原因（锁屏、显示器睡眠、系统睡眠、会话不活跃）一起出现时，只有全部解除才恢复。离开期间的会议时间在恢复时累计一次，避免重复扣减。

## 会议模式

- 用户手动开启并选择 15 / 30 / 60 分钟，默认 30 分钟。
- 使用时间仍然累计，到休息时间只改变图标，不展示全屏遮罩，不播放休息结束声音。
- 会议时间到后保留 60 秒续时窗口；续时后继续会议，未续时再恢复普通提醒。
- 已经处于主动休息时开启会议，会回到待休息状态，不将未完成的休息记为完成。
- 关闭会议或修改设置本身不会替代「等待回来」所需的新活动。

## 设置与生命周期

- 使用时长 1–120 分钟，休息时长 10–300 秒，延后时长 1–30 分钟。
- 修改时长保留当前阶段已经经过的时间；等待下一轮时按最新设置开启。
- 外观默认为跟随系统；可指定浅色或深色。
- 系统减少动态效果时停止图图走动；减少透明度时全屏采用不透明背景。
- 登录启动默认关闭，需用户主动开启；系统可能要求在登录项设置中批准。
- 退出再启动从新的使用周期开始，不恢复之前的剩余时间。
